# 素廓 Sukuo — 当代时尚女装买手店官网

面向 **15–40 岁女性** 的当代独立时尚女装买手品牌官网设计，采用零依赖原生前端架构（HTML5 + 模块化 CSS + ES Modules JS），以「冷调矿物灰白 + 勃艮第红」构筑极简买手空间美学。

## 核心亮点

- **非对称首屏画廊**：支持 3 组主推廓形预览与快速跳转至对应整套穿搭。
- **Lookbook 整套穿搭热区导购**：3 套完整造型（建筑感通勤廓形 / 柔光晚间剪裁 / 松弛学院叠穿），画报光点与右侧单品清单双向联动高亮，支持单件选码加购与一键「整套加入购物袋」（自动触发 `¥120` 整套立减礼遇）。
- **12 款双视图单品目录**：支持品类、穿衣氛围（青春松弛 / 都市通勤 / 轻熟优雅 / 约会微光）、廓形与关键词组合筛选；支持卡片色片实时换色及 **棚拍实景 ↔ 工业制版平面图** 一键切换。
- **动态尺码制版弹窗**：切换 `XS / S / M / L` 尺码实时更新 SVG 服装线稿上的厘米尺寸标注。
- **廓形与织物工坊**：建筑 H 型廓形、斜裁流体 A 摆、微收腰短廓形三大版型结构蓝图与面料手感标尺。
- **完整前端购物闭环**：基于 `localStorage` 持久化的购物袋与收藏夹、包邮门槛进度条、体验优惠码 `SUKUO10`（额外九折）及模拟结算确认。

## 本地预览

由于项目使用原生 ES Modules（`<script type="module">`），请通过任意本地静态服务器打开，例如：

```bash
# 使用 Python
python -m http.server 8765

# 或使用 Node.js (npx)
npx serve .
```

启动后在浏览器访问 `http://127.0.0.1:8765` 即可浏览。
